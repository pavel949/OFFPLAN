## Выпуск

GitHub workflow [41821231881](https://github.com/pavel949/OFFPLAN/actions/runs/41821231881) остановился до изменения базы: отсутствуют credentials GitHub Actions. Доступ MCP и переменные Vercel не заменяют эти credentials. Их создание/настройка требуют отдельного подтверждения владельца через защищённый механизм.

Перед будущим изменением схемы: сверить удалённую историю, проверить SQL на отдельной тестовой БД, подтвердить резервную копию и восстановление. `db push` не является способом устранить расхождение номеров; не редактировать production history вручную. Текущий набор улучшений приложения не требует изменения схемы или production-данных.
