Базовая проверка 2026-11-04 выполнена после PR #26–29 (main `8a6434b`); ниже учтено последующее наполнение Sudara.

## История

После наполнения Sudara 04.11.2026 рабочая история содержит 34 миграции: от `20250402000000_init` до `20261104131638_allow_sudara_source_import`. Новая миграция добавляет только допустимый код четвёртого застройщика в закрытом разделе источников; grants/RLS и существующие строки не меняются. До этого среза было 33 миграции до `20261104111218_sales_publication_and_inquiry`. Номера и названия совпадают с файлами `supabase/migrations` в подготовленной ветке наполнения. Это проверка истории, а не повторное применение SQL и не доказательство всех пользовательских процессов.

Три ранее расходившихся номера исправлены в PR #26: `20261104055146_revoke_guard_trigger_fn`, `20261104075835_project_photos_bucket`, `20261104093648_cv_methodology`. Не возвращать старые номера и не запускать их повторно. Старые миграции PR #3 объединены в `20261103170252_consolidated_market_model`; не добавлять их отдельно.

## Выпуск

GitHub workflow [41821231881](https://github.com/pavel949/OFFPLAN/actions/runs/41821231881) остановился до изменения базы: отсутствуют credentials GitHub Actions. Доступ MCP и переменные Vercel не заменяют эти credentials. Их создание/настройка требуют отдельного подтверждения владельца через защищённый механизм.

Перед будущим изменением схемы: сверить удалённую историю, проверить SQL на отдельной тестовой БД, подтвердить резервную копию и восстановление. `db push` не является способом устранить расхождение номеров; не редактировать production history вручную. Наполнение Sudara описано в DEVELOPER_IMPORT; к старому выпуску исправлений приложения оно не относится.

## Границы проверки

Схема содержит каталог, организации и роли, inventory, сделки, доказательства и расходы, источники и материалы, фото, юридические темы, версии ClearView, лимиты запросов и условия продаж. Наличие таблиц не подтверждает полноту рыночных данных, актуальность цен, доставку уведомлений или прохождение сценария конкретным пользователем. Для эксплуатации сверяться с [README](../README.md), `/admin/readiness` и проверять сценарии с действующими ролями и данными.

Промежуточные отчёты сохранены в [архиве](archive/MIGRATION_STATUS_2026-11-04.md). Указанные там количества строк, публикаций, тестов и состояния инструментов относятся к моментам отдельных проверок и не описывают текущую базу.
