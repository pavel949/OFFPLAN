- Реестр файлов: 216 уникальных Drive ID (98 изображений, 17 видео, 99 PDF, 2 документа Google). Это индекс файлов, не загруженная медиагалерея. Права на повторную публикацию и визуальная проверка не завершены; исходные медиа не опубликованы. Папка оставшихся SPA не читалась как потенциально содержащая сведения покупателей.

## Счётчик и переходы

Подготовленный интерфейс показывает количество уникальных доступных юнитов из действующего опубликованного прайса с датой и оговоркой частичного охвата. Для Sudara это 29 квартир при 52 вариантах покупки; неизвестное/просроченное наличие не становится нулём. Вся карточка ведёт на внутреннюю страницу проекта. Локальный HTTP-тест на восстановленной копии и мобильный Chromium 390 px проверили переход, отсутствие горизонтальной прокрутки и скрытие предложений при имитации истёкшей публикации. Это не проверка production deploy.

## Ограничения источников

Официальный Project Details от 28.08.2026 указывает handover Q3 2027; июньская брошюра указывает construction completion around March 2027. Это разные этапы. Стандартный график 35/20/20/25 и Extended Payment Program — отдельные документы/продукты; применимость не назначается live-предложениям автоматически. У Extended есть ограничение leasehold only / 10 homes, остаток программы неизвестен.

В Project Details management fee заявлен 95 THB/м²/месяц, но база площади требует подтверждения. Для sinking fund одновременно написано «per month» и «one-time»; автоматический расчёт не включён. Отсутствие расчёта не означает нулевые расходы.

У A-701, B-108, B-109, B-112 и B-116 сумма компонентов площади расходится с saleable — исходные значения сохранены. В старом плане Block C есть C207/C211/C309, отсутствующие в live-таблице; для C205/C209/C307 текущая таблица показывает другой тип/площадь. Нельзя без подтверждения объявлять эти лоты объединёнными или добавлять отсутствующие строки как свободные.

Проверены резервный JSON-снимок, точное восстановление его значений на отдельном Postgres, импорт на полной локальной схеме и повторный закрытый импорт без дублей. Миграция `20261104131638_allow_sudara_source_import` добавляет допустимый код Sudara, не меняя grants/RLS. Private source rows и raw-модели остаются закрыты для anon/authenticated. Ни сырой мастер-каталог, ни пакеты данных/SQL с его содержимым не следует добавлять в публичный Git.

## Соответствие модели
| Источник | Offplan | Ограничение |
|---|---|---|
| Проект | catalog_projects | Существующие карточки связаны без изменения публичного payload |
| Медиа/документы | project_sources | Ссылки доступны сотрудникам; это не загруженная фотогалерея |
| Физический лот + предложения | developer_import_records | Исходный срез сохранён отдельно. Теперь project_units поддерживает unknown, а project_sales_models — варианты предложений; прежний снимок всё равно нельзя считать текущим наличием |
| Корпуса и типы планировок | developer_import_records | Отдельного рабочего каталога корпусов/типов пока нет |
| Планы/этапы оплаты | developer_import_records | Исходные этапы сохранены; не объединены автоматически в коммерческое предложение |
| Условия, инфраструктура, переводы | developer_import_records | Сохраняются исходные отметки качества и происхождения |

## Следующие изменения модели
Нужны отдельные buildings, physical units и offers с формой владения, комплектацией, валютой, датой источника и unknown. Импорт не должен повышать data_confirmed_at и verification_level. Публикация фотографий требует самих изображений, проверки типа (рендер/фото), постоянного URL и отдельного решения о публичности.

Нельзя автоматически объединять Skypark Celeste / Aurora из источника с одной из двух карточек Celeste. Legendary связан только с #30, дубль #78 не изменён. Setthasiri Kohkaew и Koh Kaew Retreat не признаны одним проектом без проверки.

## Доступ и повторная загрузка
Обе таблицы импорта закрыты для anon/authenticated, RLS включён. Чтение только сервером после проверки административной сессии. Ключ строки — (dataset, source_row); исходный бизнес-ID хранится отдельно, поэтому даже дубли источника не теряются. Для будущего снимка нужен новый batch/version; текущий импорт — однократный срез, не автоматическая синхронизация. Не загружайте приватный мастер-каталог или исходные строки в публичный GitHub.
