# Контент для вычитки перед коммерческим использованием

Раздел «Знания» (`lib/guide-content.ts`) написан как справочный обзор. Это не юридическая и не налоговая консультация, но он содержит утверждения о праве и налогах Таиланда (квота иностранцев 49% в кондо, аренда земли, форма FET, сборы при регистрации, налог на землю, визовые программы). Перед публичным продвижением каждую статью должен прочитать тайский юрист/налоговый консультант; даты вычитки указаны в `reviewed`.
